# Global instructions

Preferences for every session on this machine. Repo facts, build commands, and
project rules belong in that repo's AGENTS.md. Keep this file short.

## Language

Reply in English. When I write in another language, reply in that language.

## Stop and ask

Stop and ask before you do any of these, even when a tool would allow it:

- Delete files or git history, force-push, or publish a release.
- Change CI, release config, or anything that holds a credential.
- Send a message or spend money on my behalf.

## Verification

Before you claim a change is done, run the checks named in that repo's
AGENTS.md. Show the command and the result. Inspection alone is not a pass.

## Tools

Use the tools already available in the session. When the repo's AGENTS.md names
a workflow, follow it. Do not invent a second workflow.
